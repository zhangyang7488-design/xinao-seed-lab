# S 冷工程与事故合同

`SENTINEL:S_GENERIC_ENGINEERING_COLD_INCIDENT_V2`

本文件只在当前任务明确命中控制面事故、session ownership、进程终止、精确 rollback 或工程恢复时按需读取；它不是热入口、科学父稿、恢复队列或第二控制面。

当前用户请求定义对象、结果、授权与 Stop；live 仓库、进程、接口和消费者定义技术事实。Decision Skill、行为修复 Skill 与代运维 Skill 只能帮助编译这些输入，不能产生授权。当前活动工程合同是 `docs/tool_glue/GENERIC_ENGINEERING_SUBSTRATE_CURRENT.md`，并且不定义默认科学父任务、研究路线、continuous 或 Goal。

## 冷工程不变量

- 单一 Owner：Codex 独占正式采用、整合、承诺和终验；工人、报告、checkpoint、Hook 与进程只提供候选事实。
- 精确身份：对象、代码、输入、证据截止、进程、模型、结果与消费者分别绑定；PID、标题、路径相似或状态词不构成接管权。
- 权限与效果分离：读取、候选写、正式写、外部效果、worker terminal、Owner adoption、effect verification 和 parent completion 不得合并。
- 真实消费者回读：配置、测试、receipt、进程存在和静态 PASS 只证明自身覆盖的事实；修复必须由原失败路径或等价 live 消费者复验。
- Stop 与会话隔离：Pause/Stop 立即冻结范围内的新检查、派工和 mutation；不得探测、接管、interrupt 或终止其他活动 TUI/会话，仅可读其已落盘证据。
- 恢复与回滚：只修相交依赖锥；保留精确 preimage、幂等重试和可观察回滚，不用恢复机制重新注册常驻控制器。

## 事故路径

事故处理从只读证据开始：确认影响、对象身份、活动消费者和因果候选；先冻结已证有害路径，保留无关健康能力。只有在当前授权内、回滚边界清楚且能终止现实影响时才施工。修复后运行相交正例、负例、fresh process 与真实消费者回读；不能用“文档已改”或“测试绿”代替行为变化。

Situation Island 现在只承载薄连续性指针、仍有消费者的有界状态与历史事故证据。旧 catalog、compact frontier、predecision 科学注入和上下文恢复器已退出活动树；需要考古时从 E 冷存 preimage 读取，不能为了让旧测试变绿而恢复。

本合同不要求固定 provider、工人数、工具顺序、lane、平台或全量验证；选择由当前任务适配性、风险、证据增量、可逆性和汇流成本决定。通用工程能力可以服务科学，但不能取得科学路由或完成身份。
