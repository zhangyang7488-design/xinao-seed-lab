# 通用工程承载合同（当前活动）

`SENTINEL:GENERIC_ENGINEERING_SUBSTRATE_CURRENT_V1`

## 身份与边界

本合同只约束可复用的工程执行能力，不定义任何科学父意图、研究问题、研究路线、候选新颖性、继续/停止研究的理由或科学完成状态。

当前人话定义要取得的结果、对象、授权与 Stop；live 仓库、进程、接口和消费者定义技术现实。科学层可以调用本合同下的能力，工程层不能反向决定科学是否开始、研究什么或何时结束。

旧 `SOFTWARE_TOOL_GLUE_CURRENT.md` 已从活动树移除，可从 Git 与 E 冷存恢复；其中混合的 `continuous`、情况岛、旧热层和新澳科学路由语义不属于本合同，也不得由本合同的消费者恢复。

## 必须保留的工程不变量

- 精确身份：输入、模型、代码、进程、证据截止、工作键、结果对象和真实消费者必须可区分；路径、标题、PID 或报告不能冒充身份。
- 权限与写域：读取、候选写入、正式采用和外部效果分账；Owner 是每个具名 effect scope 内唯一的正式责任席，其资格、任命与持续合法性分离，产品/provider/model 身份、完整 prompt、工具能力或 worker terminal 均不自动授予正式采用权。工人只在授权对象与写域内产生候选。
- 生产力选路：在父结果、消费者、完成尺与硬边界成立后，统一消费主入口 `$productivity` 的相对基线、行动/不行动对称和非支配关系。S 只承载工程效果与 readback，不复制完整正定义，不新增生产力状态机、评分、ledger 或准入器。
- 状态分离：`worker_terminal`、`owner_adopted`、`effect_verified` 与 `parent_complete` 彼此独立；一个成功运行或一份回执不自动形成上层完成。
- 执行真实性：launcher/receipt 证明实际按何种合同运行并产生什么对象，不评价科学意义；无回执对象可作为未验证候选，并可由 Owner 独立复验，不能仅因来源旁路而永久失去采用资格。
- 幂等与恢复：按预期工程效果识别重复；相同执行键采用 attach、reuse、recover、safe retry 或 conflict 分型，不能把科学问题相同误当成禁止独立复现。
- 隔离与回滚：并发写域隔离；正式改变前保留相称的可恢复来源；失败只影响相交依赖锥，不能吞掉健康兄弟工作。
- 真实消费者：测试、Schema、哈希、报告与静态检查只提供证据；完成必须由原消费者或等价 live readback 验证。
- 证据诚实：保留失败、partial、未知和不确定执行状态；不得用 accepted、绿色测试、文件数量或 token 数冒充现实效果。
- 输入与隐私：只消费任务提示和明确提供或在授权工作区内可发现的材料；不得推断、索取或复制未提供的 Codex 私有对话、私有 Plan、秘密或其他会话状态。
- Stop：用户的 Pause/Stop 立即冻结范围内的新派工、新 mutation 和续跑并保全现场；工程恢复机制不能自行越过。
- 资源与存储：普通运行状态和近期证据落 D，仓库与可恢复历史落 E，C 只承载用户可见入口和必要句柄；不复制秘密，不向未授权对象扩张效果。

## Owner 与工人

Owner 的载体由当前用户话语与 live 合同按 effect scope 任命，而不由产品名决定；同一 scope 同时只有一个正式责任席。当前 Codex 只有在被任命为该工程/effect 责任席时，才亲自接触相应源对象与真实消费者，完成整合、正式采用和终验；这不把它提升为另一个研究世界的平行认识主体。在该 S 工程/effect 职责锥内，普通 Grok WorkerPool 是可分离、可独立验收且正收益劳动的默认执行面，宽度动态，不需要用户逐项批准；Terra/Luna/native/direct 只有在当前 task-fit 事实胜出时替代。普通外部 WorkerPool 可在继承并收窄的责任锥内形成局部问题，返回始终是候选。这个劳动默认不进入 world-owning Sol 的领域 cognition；候选的认识价值由当前 cognition subject 或 fresh fusion 形成，正式共享写入与外部效果由当前 effect Owner 承担。

工人数、provider、prompt、算法名和输出包不同不证明认识异质；这项领域判断留给当前被任命的 cognition subject 或 fresh fusion，而不是 S 的 effect Owner。工程入口只保证运行边界和事实血缘，不建立科学准入法院，也不把任何 provider 固定成默认认知路线。

## 严格结果截止下的文本展开

对来源身份不足、可能携带截止后结果的 UTF-8 文本，`scripts/preflight_outcome_boundary.py` 提供同一字节快照上的 `scan` 与条件 `emit`。`emit` 只有在该快照未命中字面截止周期或显式截止后消费标记时才输出原字节；拒绝时正文保持不可见，只返回路径、哈希、字节数和原因码。路径、候选编号或先前摘要不能替代这一步。

这是窄机械护栏，不是语义安全证明、科学准入器或 Reveal 授权。`ALLOW` 不能排除自然语言改写、编码、加密或外部引用中的结果信息；高风险未知材料仍须按当前任务边界 fail-closed。当前 cognition subject 与 effect Owner 都不能用工具绿灯降低证据截止。

## 变更与验收

工程改动先绑定真实消费者和可观察失败，再做最小可回滚实现；只补覆盖相交风险的验证。对本合同的验收至少包含：原入口运行、负例、fresh process、消费者 readback、重复执行分型、越界拒绝和回滚可用性。

任何同步脚本、投影、Skill、Hook、测试或 catalog 若重新把旧科学控制语义写回本合同或正式消费者，视为回归失败；不得靠更高优先级文字覆盖。
