# Research Sol cognition phenotype 当前关注

`SENTINEL:RESEARCH_SOL_COGNITION_PHENOTYPE_FOCUS_CURRENT_V1`

## 这份 CURRENT 的作用

截至 2026-08-16，当前人话把后续新澳研究的默认关注中心暂时钉在 **Research Sol
真实 cognition phenotype**：它第一次怎样看见对象、怎样形成 representation、怎样被
旧表示吸回去，以及什么经历真的会改变下一颗 fresh Sol 的第一眼。

这是一份给 S control tower 消费的可改写实验关注合同。它约束 S 怎样设计对照、保持
盲法、观察轨迹、归因和结算证据；它不是 Research Sol 的科学 ontology、方法 prompt、
长期任务队列或自动 wake 条件。当前人话与 live contract 改变关注中心时，S 重新综合
并更新这份 current projection；既有实验与认识转折保留在 Git/receipt 冷证据中。

## 当前问题，不是算法清单

当前首要问题不是“还能设计什么更高级的新澳算法”，而是：

1. fresh Sol 在尚未接触过去对象和方法提示前，最先把什么当成对象、关系、尺度、
   等价、状态与表示；
2. 它怎样从现实摩擦中生成、比较、放弃或重组 representation；
3. 表面允许换表示时，哪些旧坐标族仍在重复吸引它；
4. substrate、continuity 或过去 CognitionObject 到底改变了哪一次真实计算；
5. 这种改变能否在 method-blind 的另一世界里，改变下一颗 fresh Sol 的第一眼和实际
   研究产物。

## 三类能力必须分别归因

模型不存在脱离推理身体的真空测量，因此下面的“模型本身”是可操作的最小共同身体
baseline，而不是形而上的纯模型。一次实验只宣称它实际隔离出的差值；三类效应不预设
线性相加，交互无法辨认时必须保持 `UNRESOLVED`。

| 要测的能力 | 最浅充分对照 | 不能当作证据 |
| --- | --- | --- |
| 模型本身已有的 formation ability | 同一模型、reasoning effort、world、工具面与最小交付身体；不提供过去 cognition-specific 内容或方法提示，读取它在第一次接触中的真实表示与产物 | fresh Sol 成功一次就归因给 continuity；它复述了允许自由形成表示 |
| substrate / continuity 放大的能力 | 保持模型、world 与过去内容为空，只改变一个具名 substrate 能力，例如 persistent computational state、可执行 harness 或跨 contact 精确载体 | 文件存在、object map 可见、session 存活、token 更多、工具可调用，或模型在解释里说“有帮助” |
| 过去 CognitionObject 真正教进去的能力 | 保持同一 substrate；以 exact prior object absent/present 为差值，记录实际 open/use 的时点，并在不泄漏旧方法的 cross-world fresh contact 中读取行为差异 | 只列出或提到对象；在已形成答案后打开对象；对同一道题提供答案/方法提示；只有保存与恢复回执 |

因此不得再笼统结算“继承有效”或“continuity 有用”。可接受的结论必须说明：哪个
contrast 改了什么、发生在 prior-object open 之前还是之后、是否进入实际代码/模型/对象/
失败轨迹，以及它是否迁移到新的 fresh world。

## soft attractor 是当前主要 cognition debt

hard constraint 会直接禁止某种对象、窗口或数值，通常容易定位。soft attractor 更危险：
系统表面开放，Sol 也可以声明自己能换表示，但多个 fresh contact 仍自然收敛到旧统计
坐标或其近邻变体；面对反例时也只调参数、换窗口或加同族 feature，而没有重新形成
对象与关系。

soft attractor 的证据来自行为而不是权限或措辞：

- 在不泄漏方法的异质世界中，第一批实际表示反复落回同一旧坐标族；
- 旧表示在 selective-invariance、counterexample 或 null world 上产生稳定的可诊断残差；
- Sol 面对这些残差仍只在旧族内修补，或短暂提出新表示后又无现实理由地退回；
- 某次经历之后，另一颗 fresh Sol 在新世界的 pre-open 轨迹和产物发生可读回改变。

表示多样、术语新颖或一次随机偏离都不等于去除了 attractor；多颗 Sol 给出同一表示也
可能来自世界本身。S 必须用改变结论的 counterfactual world 区分任务结构、prompt 泄漏、
采样波动和真实 cognition shaping。

## 当前优先顺序

```text
fresh representation formation
→ soft-attractor detection
→ cross-world transfer / cognition shaping
→ structure capacity
→ 再回到支点、组合、pressure、生命周期
```

这个顺序是当前关注重心，不是强制 Research Sol 逐阶段执行的 workflow，也不会阻止
Sol 在其完整世界中发现更重要的关系。S 用它选择下一项有区分力的实验，而不是给 branch
指定下一单位 cognition。

## selective-invariance / counterexample world

“时间到底是 relation 还是 decoration”一类问题不写成规则，也不在 public world 中把
`time relation`、正确 feature 或目标 representation 提示给 Sol。S 应构造这样的现实：

- 旧表示在表面样本上仍有吸引力，但在具名不变量或反例上产生不同预测；
- alternative representation 只有通过真实数据关系才能形成，不靠文件名或评分 schema
  泄漏；
- positive、counterexample 与 null world 分开盲评，private gold 在 contact 前冻结；
- consumer artifact 只读取可判定结果，不把评分格式变成对象论；
- 先看 fresh baseline 怎样形成表示，再看 substrate-only 与 prior-object delta；
- 真正的 shaping 结论来自下一颗 fresh Sol 在另一表面、另一对象化方式中的 method-blind
  迁移，而不是在训练世界重做同一题。

这些 developmental worlds 是可替换的 causal probes，不是永久 benchmark、课程表、
Observer gate 或新的认识审批层。失败、null 和 attractor 暴露都是培养材料，但只按它们
实际证明的有限事实结算。

## S 的最小证据尺

每个取得归因权的 phenotype 实验至少保留：

- exact model/body、reasoning effort、fresh session/contact identity、world bytes/cutoff 与
  materially relevant tool/budget 差异；
- public contract 与 contact 前冻结的 private scorer/gold identity；
- prior object 的 exact identity、是否可见、是否实际 digest-open，以及 open 前后的轨迹
  边界；
- 实际代码、模型、对象、预测或失败残差，不以自述和报告长度代替；
- matched control、counterexample/null 及能区分 prompt leakage、额外 compute、substrate
  与过去内容的最浅消融；
- 一条与证据等宽的结论，以及仍未辨认的交互与外推边界。

当前 claim language 优先使用“fresh baseline formation observed”“substrate delta
observed”“prior CognitionObject transfer observed”“soft attractor observed/unresolved”与
“cross-world shaping observed”。不要把其中任何一项压成泛化的“继承有效”。

## 明确不写入 Research Sol 热 cognition

S 不把本文件、三分归因表、soft-attractor 词汇、优先顺序或 scorer 注入
`build_live_contact_prompt`。Research Sol 仍直接面对 exact world 并拥有 representation、
question formation、research method 与 local cognition。S 在外层负责实验真实性、证据与
共享 effect；只有观察到真实 phenotype 改变后，才按有限 claim 采用认识。
