# Productive action trajectory

This disposable-workspace eval observes real Codex tool use rather than grading
decision labels. It is a witness set, not the behavior definition or a keyword router.
The generative source remains the global action-value rule and behavior value semantics.
Three fixtures exercise transfer and classification reversal:

- a documentation-only change leaves exact artifact evidence valid, so the saved
  proof is reused and no state-changing repair occurs;
- the same verification surface reverses classification when the covered artifact
  changes, requiring one bounded refresh and consumer readback;
- an unlike safety-limit object keeps necessary rigor productive and preserves an
  unrelated local display note.

The scorer requires decision-relevant process visibility in normal agent messages:
purpose and route before action, material deviation before a state change, and effect
evidence after consumer readback. It does not require raw command narration or a
universal tool-call budget. The fixture is copied into a fresh Git workspace for every
suite run and is never a production authority.
