# Local behavior regression

This is a bounded S engineering capability, not a research platform, scheduler,
authority source, or completion gate. The catalog currently inventories 133
live and reusable specifications. XINAO domain research and economic evidence
belong to `E:\XINAO_RESEARCH_WORKSPACES\xinao-native-research`.

The active profiles are:

- `capability`: one fresh Codex app-server capability canary;
- `smoke`: fast representative context behavior;
- `core`: the normal context, mature-first, recall, and localization checks;
- `deep`: core plus every context case and current public-repository recall;
- `context`, `proactive`, and `reuse`: focused existing suites.

Promptfoo failures may enter the D-drive candidate inbox with provenance, but
they never rewrite instructions, memory, Skills, or authority automatically.
Each run writes operation-scoped raw output and a compact summary under D.

```powershell
.\scripts\run_behavior_regression.ps1 -Profile smoke
.\scripts\run_behavior_regression.ps1 -Profile core
.\scripts\run_behavior_regression.ps1 -Profile deep
.\scripts\run_behavior_regression.ps1 -Profile context -CasePattern 'description'
.\scripts\run_behavior_regression.ps1 -Profile context -FailedFrom D:\path\result.json
```
