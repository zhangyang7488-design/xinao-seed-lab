# Current Prime baseline adoption

`SENTINEL:PRIME_BASELINE_COMPATIBILITY_ADOPTION_V1`

The test is an upgrade branch of the current Prime runtime, not a wholesale copy of the current island contract.

Adopted from the current Prime baseline:

- native TUI, daemon socket, exact JSONL resume, compaction, kernel, RLM child registry and model/provider behavior;
- profile settings, keybindings and Windows/model-catalog compatibility shims;
- the useful causal parts of `understand-and-steer-prime`: live session identity, native reload/steer/follow-up/abort distinctions, request/acknowledgement/consumption/effect accounting, and Prime-specific runtime diagnosis;
- generative behavior cases around current-user-versus-pasted material, correction reset, live facts, mature-first thin glue, candidate/adoption/effect separation, Stop and simple-task non-escalation.

Deliberately not copied:

- the old island's whole `AGENTS.md`, contracts, scientific routes or second behavior constitution;
- its absolute sentence that Prime can never hold external formal Owner authority. The surviving relation is provider-neutral: behavior consumption creates eligibility; current words/live contract may appoint exactly one formal Owner for one named effect scope;
- junctions from the mutable Prime surface into canonical Codex Skills or behavior sources;
- old regression fixtures as an authority source. The new held-out and reversal cases independently witness the shared relation.

This selection prevents both failure directions: losing Prime-native advantages by rebuilding it as Codex, and preserving stale island-specific authority rules merely because they were already written.
